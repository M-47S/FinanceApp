# 🏦 Finance App: Личный финансовый менеджер с ИИ

> Десктопное приложение для контроля, анализа и управления личными финансами. 
> Включает в себя гибкую аналитику, работу с базой данных PostgreSQL, загрузку отчетов из Excel и встроенного **ИИ-ассистента (GigaChat)**.

---

## 🌟 Ключевые возможности

- 📊 **Продвинутая аналитика**: Выбор конкретных таблиц, столбцов и лимитов, а также режим `SQL-Mode` для написания собственных запросов.
- ✏️ **Управление данными**: Интерактивное редактирование и удаление записей с защитой внешних ключей (FK).
- 📥 **Импорт данных**: Загрузка транзакций из Excel-файлов и поддержка кастомных месячных отчетов.
- 🤖 **ИИ-Ассистент**: Встроенный чат на базе GigaChat. Поможет с анализом, текстом или кодом. Работает асинхронно, не блокируя интерфейс, и поддерживает рендеринг Markdown.
- 🔐 **Разграничение прав (RBAC)**: Разделение на роли `Admin`, `Writer` и `Reader` на уровне PostgreSQL.

---

## 🛠️ Технологический стек

| Компонент | Технологии |
| :--- | :--- |
| **GUI (Клиент)** | Python 3.11+, PyQt6 |
| **API (Бэкенд)** | FastAPI, Uvicorn, Pydantic |
| **База данных** | PostgreSQL 16 |
| **Данные** | Pandas, OpenPyXL, psycopg2 |
| **ИИ** | GigaChat API (через OpenAI SDK), httpx |
| **Деплой** | Docker, Docker Compose *(см. ветку `Deployment_branch`)* |

---

## 🏗️ Архитектура проекта

Проект разделен на независимые слои. Взаимодействие с базой данных происходит **только через API**. Клиент (GUI) не имеет прямого доступа к БД.

```text
[ GUI (PyQt6) ]  ──(HTTP/JSON)──>  [ API (FastAPI) ]  ──(psycopg2)──>  [ PostgreSQL ]
       │                                  │
       └───(HTTPS)───> [ GigaChat API ]   └─── (опционально) ───> [ Docker (Cloud) ]
